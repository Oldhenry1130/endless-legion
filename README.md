# 無盡軍團

網頁版軍團跑道射擊遊戲。左右移動軍團射殺怪物、穿過數字門增加兵力、撿武器與支援道具，打通 20 個關卡，再用獎金建設基地。

線上遊玩：https://oldhenry1130.github.io/endless-legion/

## 玩法

- **關卡制**：20 關，每關 5000 m。0–3000 m 普通、3000–4000 m 中等難度、4000–5000 m 高難度，途中有大王連戰。
- **場景與線道**：每 5 關換場景（翠綠平原、烈日荒漠、冰封雪原、熔岩地獄）；第 1–7 關 2 線道、第 8–14 關 3 線道、第 15–20 關 4 線道。
- **獎金**：擊殺、每 1000 m 里程、路上的金幣道具、通關獎金（首次通關 ×1.5）。中途陣亡也保留已賺到的獎金。
- **基地**：10 種設施——兵營、軍火庫、訓練場、瞭望塔、防具工廠、能量核心、金庫、武器工坊、多重武裝（同時裝備 2～3 把武器）、空軍基地（定期轟炸支援）。
- **兵團**：6 種外觀可解鎖與切換。
- **武器**：12 種，各有效果（擊退、暴擊、減速、扇形散射、爆炸、自動追蹤、穿透、燃燒、連鎖閃電、貫穿光束）。
- **支援道具**：飛彈艙、雷暴、能量護盾、攻擊無人機，撿到後在時間內自動作戰。
- **天罰降臨**：殺怪充能，集滿後雙擊畫面（或空白鍵、點右下角按鈕）施放，清除全場敵人。

## 操作

滑鼠／手指左右移動，鍵盤 ← → 或 A / D；雙擊畫面或空白鍵施放天罰降臨；P 或 Esc 暫停。

進度存在各自瀏覽器的本機儲存空間，換瀏覽器或清除網站資料會重新開始。
